# Gravity-cliff follow-up protocol

This is exploratory development after the prior SPARC holdout was disclosed. No galaxy in this catalog is claimed to be newly unseen. Keep the original run untouched. Use its loader, ordinary-matter models, quality cuts and k. Main sample uses only catalog distance methods 2, 3 and 5 (TRGB, Cepheids, supernovae); no Hubble-flow or cluster-distance galaxies in training or evaluation. Other calibration assumptions remain.

Five-fold whole-galaxy cross-validation: sort names by SHA256('option3-cliff-v1:'+name), then assign index modulo 5. Each galaxy receives one out-of-fold prediction. No per-galaxy adjustment. Use the same galaxy-balanced log-speed MSE objective and secondary percentage and km/s errors as the prior run.

Define s=max(0,-d ln(gbar)/d ln(r)) and C=s/(1+s). Estimate the slope by a quadratic least-squares fit to the nearest five consecutive radial samples in log radius, centered at the requested point; shift the window at boundaries. This feature uses only radii and the ordinary-matter model, never observed velocities. It measures declining acceleration, not gravitational potential depth. Primary extension: a_extra=A aK (gbar/aK)^p exp(beta C). Bounds log10 A [-5,1], p [0,1], beta [-ln 2,ln 2], allowing a modest half-to-double multiplier at fixed A,p. Baseline: same model with beta=0. Reference: standard RAR with one fitted acceleration scale. Ordinary matter baseline also scored. One prespecified sensitivity uses a three-point instead of five-point slope. No candidate selection on these data, no further searches.

Persist fold membership, fitted fold coefficients and out-of-fold predictions. Report paired whole-galaxy bootstrap interval (5000 resamples, seed 20260909) for baseline-minus-cliff log RMSE; conditional exploratory interval, not a formal discovery significance because folds share training sets and the catalog informed prior work. Report coefficient sign/stability and outer radial third. Full-sample fitted coefficients, if computed, are deployment/development estimates only, never evaluated as holdout results.

Separate consistency calculations use the prior frozen A,p, not refitted cliff coefficients: (1) test whether the naive vector extension of extra acceleration is curl-free, by integrating two paths in a specified flattened toy baryonic potential (Miyamoto-Nagai form; M=5e10 solar masses, a=3 kpc, b=0.3 kpc, endpoints (R,z)=(3,0.3),(15,3) kpc); (2) derive static-clock photon endpoint shift and lensing dependence on the two weak-field metric potentials. The toy is not an observed galaxy or a vertical/lensing data test. Verify numerical quadratures by tightening tolerances, and include the Newtonian conservative-field control.

Do not claim to derive the redshift coupling: free A still absorbs k. A static scalar field cannot supply path-length redshift between equal-clock endpoints under stationary metric photon propagation. A Poisson projection is a possible scalar-field completion, related to known QUMOND, but it changes nonspherical predictions and must be solved/refit before observational claims. A cliff-dependent extension is not automatically an action-based or conservative full matter-field theory.
