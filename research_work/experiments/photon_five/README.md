# Five photon-response experiments
This is a separate static-universe campaign. Its five proposed mechanisms are tested without a dark-matter source, fitted halo benchmark, expanding geometry, scale-factor evolution or cosmological photon-redshift operator.

Start with [the results report](report.md), [original protocol](protocol.md) and the three implementation declarations. The five mechanisms are speculative fixtures, not established physics or claims of historical novelty. The archived measurements are exposed and conditional; none is a new blind holdout.

From the repository root, with Python, NumPy, SciPy and matplotlib installed:

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B research_work/experiments/photon_five/run.py --stage radiation --output research_work/generated/pf5-radiation-new
python -B research_work/experiments/photon_five/run.py --stage transport --output research_work/generated/pf5-transport-new
python -B research_work/experiments/photon_five/run.py --stage fluctuations --output research_work/generated/pf5-fluctuations-new
python -B research_work/experiments/photon_five/run.py --stage fluctuations_colored --output research_work/generated/pf5-colored-new
python -B research_work/experiments/photon_five/run.py --stage shock --output research_work/generated/pf5-shock-new
python -B research_work/experiments/photon_five/run.py --stage strain --output research_work/generated/pf5-strain-new
python -B research_work/experiments/photon_five/run.py --stage audit --output research_work/generated/pf5-audit-new
```

Use a new output directory each time; the runner refuses to overwrite evidence. A completed run records failed scientific gates in JSON and returns successfully. Execution exceptions are distinct failures, preserved in the manifest. Inspect numerical_pass, mechanism_pass and individual gates; a zero process exit status does not mean a hypothesis passed.

The saved evidence uses NumPy 2.2.6 / SciPy 1.16.1 / Python 3.13.5. Every manifest records input/source hashes and its starting Git commit; calculation sources can be recovered from that commit. Ancillary report snapshots can be committed later; verify_archive.py resolves all recorded hashes in Git history. The later runner also records package versions and the active repository module inventory. The displayed report is regenerated by consolidate.py from immutable saved evidence. No full historical suite is run here: older jobs actively compare excluded geometry and matter models. Existing failed RUT-8 and unrun RUT-9 statuses are unchanged.

Missing bolometric inputs, finite photon histories and coupled matter backreaction are reported as missing tests, never as passes. Toy photon energy conservation is distinguished from a globally funded theory.
