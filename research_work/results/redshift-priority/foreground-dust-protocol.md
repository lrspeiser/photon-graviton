# Independent foreground-dust input audit

Query IRSA DUST at the fixed coordinates of all 164 exposed galaxy groups, using coordinates rather than names. Record SFD and Schlafly-Finkbeiner reference-pixel reddening, local mean and scatter, request URL and response hash. Use two workers, retain failures and do not omit unsuccessful objects from analysis. The first-row request established the XML schema before this protocol; it was not compared with a residual.

Primary descriptive input: Schlafly-Finkbeiner reference-pixel E(B-V). Retain SFD as a provenance/comparison field, not an independent second measurement. Compare primary reddening with the saved coarse-sky constant-baseline signed residual and absolute residual using Pearson and Spearman correlations. Report the same associations after subtracting each predefined sky region's mean from each variable. These are descriptive within-region associations, not a partial physical model, causal estimate or fitted correction. Retain all 164 rows and all eight region summaries. Do not optimize a cut, remove high-dust points, refit alpha or choose thresholds after seeing results.

Milky Way foreground reddening is an independently obtained observational nuisance input; it is not intergalactic void density, gravitational potential or a photon-to-companion measurement. Existing catalog distance corrections may already account for dust. Never apply another dust correction to adopted distances without source calibration evidence. Correlation would not establish causation, and no correlation would not prove dust corrections perfect. No new-sample outcomes are involved.
