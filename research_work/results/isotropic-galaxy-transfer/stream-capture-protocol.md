# Straight-stream capture test, declared before execution

Keep k0, each original capture scale a, and eta=X^(1/3)/(1+X^(1/3)) fixed. Use the existing finite diagnostic region R=5 Re for each halo target, not a measured physical halo edge. Specify incoming companion intensity at its boundary and trace its attenuation inside: kappa=k0/[1+(r/a)^2]^2; F(s)=F_entry exp(-integral kappa ds); q_ret=eta kappa F. This tests the external already-converted component. Conversion of photons inside the region, internal stars, exterior opacity, migration and gravitational steering are not included. Unretained absorbed energy must occupy another channel; it is not destroyed.

Source cases: one point source at D/R=1.1,2,5,10,100, and uniform distant illumination. A source's boundary intensity follows L[1-exp(-alpha*d_entry)]/(4*pi*d_entry^2); its geometric dilution from boundary to position is included. alpha is the archived empirical value. The spherical average for one source equals an isotropic source shell at that distance; single-source angular asymmetry is recorded separately. Absolute L and history are unspecified. This is a boundary-conditioned experiment, not a source census around these six galaxies.

Compare normalized cumulative deposited energy inside R against each existing NFW finite target under both geometries and both population proxies. A constant common duration is assumed only to translate rate shape into accumulated shape. Normalize each to unity at R to isolate placement, never to claim sufficient energy. Report maximum cumulative fraction difference and half-mass radii. Include a deliberately generous inverse test: any nonnegative mixture of source distances, separately fitted to each target, minimizing the maximum cumulative difference. This is a diagnostic lower bound within the finite basis, not a transferable prediction. No pass threshold, new lens fit, parameter search or physical steering law is introduced.

Verify analytic optical depth by independent quadrature, monotonic cumulative profiles, far-source limit, and doubled angular/radial quadrature stability. Source input files are hashed. Report all cases and limitations.
