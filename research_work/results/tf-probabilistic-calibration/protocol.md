# Conditional uncertainty model for TF calibration

Declare before fitting: retain all 73 existing calibrators, the p=1 conditional photometry and fixed alpha. Use published logWmxi and e_logWmxi, the existing corrected i magnitude, indicator distance and its modulus error, catalog e_Ai and a conservative 0.05-mag photometry uncertainty. Do not query recession velocities or select a model using redshift outcomes.

Compare two known statistical models, neither a new physical mechanism. Both have y=a*x+b+residual, x=logWmxi-2.5. The baseline is a Gaussian residual with intrinsic scale s. The alternative is a zero-mean Gaussian mixture with core scale s, broad scale 5s and common broad-component fraction f constrained to [0,0.5]. The factor five and bound are declared analyst choices; they are not inferred properties of disturbed galaxies. Add measurement variance sigma_mu^2+0.05^2+e_Ai^2+a^2*sigma_x^2 to each component. This marginalization assumes independent Gaussian measurement errors and a locally flat latent-x prior; it is a conditional working likelihood, not a selection-corrected errors-in-variables population model.

Fit maximum likelihood with multiple starting points, s in [0.01,5] mag, a in [-20,-1], b in [-30,-10]. Leave each complete catalog group out, then record the held-out log density, predicted mean, central 68% and 95% residual interval coverage, and central-inversion distance discrepancy. No residual clipping or per-object adjustment. Retain both models irrespective of which score is better. Report convergence/boundary diagnostics and all predictions. Broad-component responsibilities are not physical classifications.

Predictive intervals include the held-out indicator measurement error so coverage tests residuals against that noisy measurement. They are not distance posteriors for galaxies without indicator measurements. Parameter uncertainty, common zero-point correlations, selection, unknown-x population and environment-dependent mixture fraction remain omitted. Do not deploy these plug-in intervals as precision void-map distances. Environment-dependent bias cannot be removed by broadening a common zero-mean scatter alone.

Verify analytic mixture quantiles by their CDF, exactly one group-excluded prediction per galaxy, and all optimizer outcomes. Compare summed held-out log scores descriptively, not as a Bayes factor, physical-model evidence or a new blind holdout. Recheck the largest-discrepancy object's inclusion. No alpha, companion law, physical-model freeze or holdout status changes.
