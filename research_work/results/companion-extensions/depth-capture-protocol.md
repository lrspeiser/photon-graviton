# Well-depth-dependent capture, with deposited-field feedback

13 September 2026; declared before execution. This extends capture of traveling
energy, rather than repeating the older binding-driven migration of stored mass.
Use the same 149 SPARC galaxies, 3150 accepted radii, ordinary-matter contributions
and 89/29/31 split. Keep exact-third eta, C0, k0 and capture scale unchanged.
All observations have been inspected previously.

Start from spherical reference opacity kappa0(r). Let S(B)=B/(B+150^2), with
B=-Phi in (km/s)^2 and zero potential at infinity. Test three proposed opacity
multipliers: boost=1+beta S; gate=1-beta+beta S; tilt=1+beta(2S-1).
Each family scans beta=0,0.25,0.5,1 only, with shared 150 km/s scale fixed before
testing. No change in the one-third exponent or separate galaxy normalization.
The saturating rational form is known mathematics; these capture applications
are hypotheses, not derived interactions. Select beta by training logarithmic
loss within each family; freeze it for validation/test. Do not enlarge the range.

Compute B_b on the disk midplane by integrating the supplied baryonic vc^2/r,
linearly interpolating vc^2 versus log radius. Beyond the last observed radius
use a finite-mass Kepler tail matching that endpoint; below the first radius use
vc^2 proportional to r^2. Extend this depth radially for spherical capture.
This is a stated sphericalization of a midplane field, not a full 3D disk/bulge
potential or independently measured escape speed. Keep ordinary-matter forces
in the rotation prediction exactly as supplied. If a nonzero rule is selected,
check sensitivity to the unconstrained outer-depth offset before promoting it.

Add the potential of the current deposited spherical density, recalculate the
opacity and ray attenuation, and solve the stationary fixed-point equation with
damping. Use the same modifier in local absorption and path interception. Retain
the absolute reference source/exposure normalization; do not force equal mass.
Uncaptured energy remains traveling in this bookkeeping model. Extra stored mass
requires additional intercepted energy, not unexplained gravitational amplification.

Track convergence, mass ratios, depth ranges, speeds, radial bias, and all failed
cases. Check zero-strength recovery, numerical ray integration and spherical
potential identities. Refine selected cases with beta frozen; compare alternate
initial densities to test seed sensitivity, without claiming dynamical stability.
If all families select beta=0, the identity result needs no expensive repeated
feedback calculation. Report small trial improvements without promoting them
when transfer, numerical precision or depth assumptions do not support them.
