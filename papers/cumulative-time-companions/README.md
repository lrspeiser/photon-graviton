## Rebuild

From the repository root:

```sh
python -m pip install -r papers/cumulative-time-companions/requirements.txt
python papers/cumulative-time-companions/build.py
```

Markdown is the authoritative editable source. The build generates a PDF with numbered rendered equations and clickable external references. Intermediate renders and local QA files belong outside this directory. Research diagnostic outputs are not modified by the build.
